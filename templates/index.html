Application Layer Standard Specifications

The Application layer operates at Layer 7 of the OSI Model and Layer 5/4 of the TCP/IP stack. It encompasses protocols that interact directly with user processes:

  • DNS (RFC 1035): Resolves human-readable domain names into IP addresses via recursive or iterative UDP queries on port 53.
  • HTTP (RFC 7230/7231): Stateless, client-server request-response protocol running over TCP (port 80/443). Uses methods like GET and POST with status codes (200 OK, 404 Not Found).
  • SMTP (RFC 5321): Stateful, push-based mail transfer protocol running over TCP port 25/587. Employs a structured command-response lockstep dialog.
  • HLS (RFC 8216): HTTP Live Streaming breaks continuous media streams into downloadable indexed chunks (.ts segments), enabling adaptive bitrate adaptation over standard HTTP caches.
